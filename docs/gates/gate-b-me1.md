## P0

- **me1-sampling-simulator** (statsim / sampling). Goal: Bernoulli trials build Bin(n, p) with mean np and SD √(np(1 − p)); sample means (and p̂ as the mean of Bernoulli values) centre on μ with SD σ/√n and look more normal as n grows. Key numbers: Bin(20, 0.3) mean 6, SD √4.2 = 2.04939; p̂ for n = 50, p = 0.4: SD √0.0048 = 0.069282; exponential λ = 1, n = 30: SD 1/√30 = 0.182574; uniform [0, 1], n = 12: SD 1/12; die σ = √(35/12) = 1.70783, n = 10: 0.540062; skewed population μ = 1.29, σ = 1.43035. Simulated mean and SD of 10 000 seeded samples are checked against theory within at least 4.9 standard errors (verified over 300 seeds); 100 steps draw exactly 100 samples.
- **me1-slope-fields** (field2d / slope-field). Goal: read dy/dx = f(x, y) as a gradient at every point; solution curves follow the field; an initial condition picks one curve; growth, cooling and logistic behaviour and equilibria. Key numbers (RK4, relTol 1e-5): y′ = y from (0, 1): y(1) = e, y(−1) = 1/e; logistic r = 1, K = 10, y₀ = 1: y(2) = 4.50853, slope there 2.47585; cooling k = 0.2 from 90 in 20 °C: y(5) = 45.7516, initial slope −14; default y′ = −xy: y(1) = e^(−1/2) = 0.606531; y′ = x − y: y(2) = 1 + 2e⁻² = 1.27067.

## P2

An independent script recomputed all 170 expected values in the P2 specs (0 failures): the arrangement formulas were compared with a brute-force enumeration for every line and circle case with n = 3 … 8 and k = 2 … 4, and the inequality checks were run through the critical-point algorithm exactly as the spec describes it.

- **me1-arrangements** (custom). Goal: count arrangements by reasoning: n!, (n − 1)! round a table, n!/(a!b!…) for repeated letters, the block method, the complement and the gap method; the pigeonhole principle; every formula checked against a brute-force count on screen. Key numbers: 5 in a row 120; 6 in a row, A and B together 5! × 2! = 240 (probability 1/3), apart 480; 7 in a row with 3 special: together 720, not all together 4320, no two together 4! × ⁵P₃ = 1440; round table of 6: 120 total, together 48, apart 72; BANANA 60; MISSISSIPPI 34 650; 13 balls in 4 boxes force 4.
- **me1-induction-dominoes** (custom). Goal: the structure of proof by induction through falling dominoes; why the base case and the step are both needed; sums, divisibility and an inequality, plus a false base case and Euler's n² − n + 41. Key numbers: Σi² to 10 = 385 = 10·11·21/6; all 12 odd-sum dominoes fall, 3 after 36 steps (12 steps per domino); 2⁴ = 16 = 4² fails, from n₀ = 5 eight dominoes fall, from n₀ = 1 the chain breaks at 2; n² + n + 1 is odd so none fall; Euler fails first at 41 (1681 = 41²), 40 fall; 5⁶ + 3 = 15 628 = 4 × 3907.
- **me1-inequality-line** (fnplot / inequality). Goal: solve quadratic and rational inequalities with critical points (zeros and undefined points), test regions and included or excluded endpoints. Key numbers: x² − x − 6 < 0: critical −2, 3 (open), x = 0 gives −6 (true), x = 4 gives 6 (false); x² ≥ 4x: 0, 4 (closed), x = 2 false; (x + 1)/(x − 2) ≥ 3: 2 (open, undefined), 3.5 (closed), x = 3 gives 4 ≥ 3, x = 3.5 gives 3 ≥ 3 but not 3 > 3; 1/x < 2: 0 and 0.5, x = 0.25 false, x = −1 true.
- **me1-inverse-trig** (fnplot / inverse-trig). Goal: build sin⁻¹, cos⁻¹ and tan⁻¹ (of x/a) by restricting and reflecting; domains and ranges; derivatives; sin⁻¹x + cos⁻¹x = π/2. Key numbers: sin⁻¹0.5 = π/6, gradient 2/√3 = 1.15470; cos⁻¹(−1/2) = 2π/3 with a = 2, gradient −1/√3, range [0, π]; tan⁻¹(2/2) = π/4, gradient 2/8 = 0.25; sin⁻¹(−1) = −π/2 with domain [−3, 3]; sin⁻¹0.6 + cos⁻¹0.6 = π/2; tan⁻¹(−2) + tan⁻¹(−1/2) = −π/2; a = 4, x = 2: gradient 1/√12.
- **me1-pascal-binomial** (custom). Goal: Pascal's triangle rows as ⁿCₖ; Pascal's identity; the general term Tₖ₊₁ = ⁿCₖ aⁿ⁻ᵏbᵏ; finding a particular or constant term; row sums 2ⁿ and coefficient sums at x = 1. Key numbers: (x + 1)⁶: ⁶C₂ = 15 = 5 + 10, row sum 64; (2x + 3)⁵: x³ coefficient 720, coefficient sum 3125; (x + 1/x)⁸: constant 70, no x³ term; (2x² − 1/x)⁶: x³ coefficient −160, constant 60; (x − 2)⁷: T₄ coefficient −280; ¹⁶C₈ = 12 870 = 6435 + 6435, 2¹⁶ = 65 536.
- **me1-substitution-areas** (fnplot / substitution). Goal: the area under f(g(x))g′(x) from a to b equals the area under f(u) from g(a) to g(b); matching strips keep their area; decreasing g reverses the limits. Key numbers: ∫₀¹ 2x(x² + 1)³ dx = ∫₁² u³ du = 3.75, strip 2 of 4 = 0.291744 on both sides; ∫₀^(π/2) cos x e^(sin x) dx = e − 1; ∫₁^e (ln x)/x dx = 0.5; ∫₀¹ √(1 − x²)(−2x) dx = ∫₁⁰ √u du = −2/3; ∫₀^√(π/2) 2x cos(x²) dx = 1.
