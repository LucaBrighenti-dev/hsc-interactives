# Gate reports

Short reports written for Luca to approve. Each one says what to check and how, in a few minutes, without reading code.

- `gate-a.md`: written by the Wave 0 lead at the end of Wave 0 (guide §8).
- `gate-b-<subject>.md`: written by each spec writer (guide §10).
- `syllabus-report.md`: syllabus mismatches found by the syllabus tagger (guide §9.4).
- `gate-c-queue.md`: PRs that passed independent review and are ready for Luca to merge (guide §12). The orchestrator is its only writer.
